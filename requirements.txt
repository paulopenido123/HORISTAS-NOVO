# Trocado o pacote "supabase" por "psycopg2-binary" na migração pra Neon
# de 10/09/2026 (banco Postgres puro, sem o SDK do Supabase por cima) --
# "boto3" foi adicionado junto porque o Neon Object Storage (que substitui
# o Supabase Storage, usado pras fotos dos consultórios) fala o protocolo
# S3, e boto3 é o SDK oficial da AWS pra isso, recomendado na própria
# documentação do Neon.
#
# psycopg2-binary está com ">=" (sem travar numa versão exata) de propósito:
# em Pythons muito novos (ex: 3.14, lançado há pouco tempo), pode não existir
# ainda um pacote pré-compilado ("wheel") pra uma versão antiga travada --
# aí o pip tenta compilar do zero e falha com "pg_config executable not
# found" (foi o que aconteceu numa instalação real em 10/09/2026). Deixando
# sem travar, o pip sempre pega a versão mais nova disponível, que já vem
# pré-compilada pro Python da pessoa.
